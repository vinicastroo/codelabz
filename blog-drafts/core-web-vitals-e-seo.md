# O Que São Core Web Vitals e Como Eles Afetam Seu Posicionamento no Google

Você já deve ter ouvido que "o Google gosta de sites rápidos". Mas o que isso significa na prática? A resposta tem nome: Core Web Vitals.

Core Web Vitals são métricas técnicas que o Google usa para avaliar a experiência real de quem navega no seu site. E sim, elas entram na conta de como sua página é posicionada nos resultados de busca.

Neste artigo, vamos explicar de forma simples o que cada uma dessas métricas mede e, principalmente, como elas se conectam ao seu SEO — ou seja, à capacidade do seu site de aparecer bem posicionado quando alguém pesquisa no Google.

## Por que o Google passou a medir a experiência da página

Durante muito tempo, o SEO girava quase só em torno de palavras-chave e links. Hoje, o Google também avalia como é a experiência de usar a página: ela carrega rápido? Responde bem aos cliques? Fica "parada" enquanto o usuário lê?

Isso faz sentido do ponto de vista do próprio Google: o objetivo da busca é entregar não apenas conteúdo relevante, mas também uma boa experiência para quem clicou no resultado.

É como um guia de restaurantes que não recomenda só pela qualidade do prato, mas também considera se o atendimento é rápido e se a mesa não fica balançando. O prato pode ser ótimo, mas a experiência completa pesa na nota final.

Os Core Web Vitals são justamente a forma como o Google tenta medir essa "experiência completa" de forma objetiva e comparável entre sites diferentes.

## O que são os Core Web Vitals, na prática

Core Web Vitals é um conjunto de três métricas técnicas que avaliam velocidade de carregamento, capacidade de resposta a interações e estabilidade visual de uma página.

Elas fazem parte de um grupo maior de sinais chamado "Page Experience" (experiência de página), que o Google usa como parte dos fatores considerados no ranqueamento orgânico dos resultados de busca.

Você não precisa entender de código para compreender o conceito. Pense nelas como os três principais indicadores de um "check-up" técnico do seu site — assim como um médico usa poucos exames-chave para ter uma boa noção geral da saúde de um paciente.

### LCP (Largest Contentful Paint): a velocidade da primeira impressão

LCP mede quanto tempo o maior elemento visível da tela — geralmente uma imagem de destaque, um banner ou um bloco de texto principal — leva para aparecer completamente para o visitante.

É como o tempo que uma pessoa espera até enxergar a vitrine de uma loja depois de abrir a porta. Se demora demais, a sensação é de que o lugar "ainda não está pronto" para receber o cliente.

Para o Google, um LCP alto sugere que o usuário passou tempo demais olhando para uma tela em branco antes de conseguir consumir o conteúdo pelo qual pesquisou.

### INP (Interaction to Next Paint): a capacidade de resposta do site

INP mede o tempo que o site leva para reagir quando o usuário clica em um botão, preenche um campo ou toca em um menu. Essa métrica substituiu o antigo FID (First Input Delay) como padrão oficial do Google.

É a diferença entre um atendente que responde na hora quando você faz uma pergunta e um atendente que demora para prestar atenção em você. Um site que "trava" ao clicar passa a mesma sensação de descaso.

Do ponto de vista de SEO, um site com respostas lentas às interações sinaliza ao Google que a experiência de uso é ruim, mesmo que o conteúdo em si seja de qualidade.

### CLS (Cumulative Layout Shift): a estabilidade visual da página

CLS mede o quanto os elementos da página se movem inesperadamente enquanto ela carrega — como um botão que muda de lugar bem na hora em que o usuário ia clicar nele.

É como tentar assinar um documento em um balcão que fica se mexendo. Além de irritante, pode levar a cliques errados e a uma sensação de que o site é pouco confiável.

Páginas com CLS alto tendem a frustrar o usuário logo nos primeiros segundos, o que pode aumentar a taxa de saída rápida — outro sinal que o Google observa indiretamente ao avaliar a qualidade da experiência.

### Resumo dos três Core Web Vitals

| Métrica | O que mede | Analogia simples | Meta recomendada pelo Google |
|---|---|---|---|
| **LCP** (Largest Contentful Paint) | Tempo até o conteúdo principal aparecer na tela | Tempo para ver a vitrine da loja | Até 2,5 segundos |
| **INP** (Interaction to Next Paint) | Velocidade de resposta a cliques e toques | Atendente que responde na hora | Até 200 milissegundos |
| **CLS** (Cumulative Layout Shift) | Estabilidade visual dos elementos na tela | Balcão que não fica se mexendo | Abaixo de 0,1 |

## Como o Google usa os Core Web Vitals no ranqueamento

Aqui está o ponto central deste artigo: os Core Web Vitals fazem parte dos sinais de "experiência de página" que o Google considera ao decidir a ordem dos resultados de busca.

Isso não significa que um site rápido "fura fila" e ultrapassa concorrentes com conteúdo muito superior. O conteúdo relevante e bem estruturado continua sendo o fator mais importante do SEO.

Mas, entre páginas com relevância de conteúdo parecida, a experiência técnica pode ser o critério de desempate. Nesse cenário, o site mais rápido e estável tende a levar vantagem no posicionamento.

Estudos do setor de SEO apontam que sites com bons índices de Core Web Vitals costumam ter desempenho orgânico mais estável, especialmente em buscas via celular, onde a navegação é mais sensível a lentidão e instabilidade visual.

### Sinais diretos e indiretos

Vale entender que existem dois tipos de impacto no SEO:

- **Sinal direto**: o Google usa os Core Web Vitals como parte do algoritmo de Page Experience, junto com outros fatores como uso de HTTPS e adequação a dispositivos móveis.
- **Sinal indireto**: um site lento ou instável aumenta a chance de o usuário sair rápido da página, reduz o tempo de permanência e prejudica a navegação entre páginas — fatores que também influenciam a percepção de qualidade.

Ou seja, mesmo que o peso direto de cada métrica não seja o fator isolado mais forte do SEO, o efeito combinado — direto mais indireto — é real ao longo do tempo.

### Mobile-first: o campo onde os Core Web Vitals mais pesam

O Google indexa e avalia a maioria dos sites priorizando a versão mobile (chamado de "mobile-first indexing"). Isso significa que a performance no celular, e não no computador, costuma ser a referência principal usada na avaliação.

Como conexões móveis costumam ser mais instáveis do que redes fixas, um site mal otimizado tende a sofrer ainda mais nesse cenário — reforçando a importância de tratar performance como parte da estratégia de SEO, e não como detalhe secundário.

## Como saber se o seu site está dentro das metas

Você não precisa ser desenvolvedor para ter uma noção do problema. Ferramentas gratuitas do Google, como o PageSpeed Insights e o relatório de Core Web Vitals no Search Console, mostram quais páginas estão dentro ou fora das metas.

Essas ferramentas apontam a nota geral e destacam qual das três métricas está prejudicando o desempenho: carregamento (LCP), resposta a cliques (INP) ou estabilidade visual (CLS).

Ainda assim, o diagnóstico completo — entender se o problema está no servidor, nas imagens, no código ou na hospedagem — normalmente exige um olhar técnico especializado, já que cada site tem uma combinação diferente de causas.

## Tratando performance como parte da estratégia de SEO

Um erro comum é tratar Core Web Vitals como um ajuste técnico pontual, feito uma vez e esquecido. Na prática, funciona melhor como parte contínua da estratégia de SEO, junto com conteúdo, palavras-chave e estrutura do site.

Isso envolve escolhas que começam ainda no desenvolvimento do projeto: hospedagem adequada, código bem estruturado, imagens otimizadas e poucos scripts desnecessários carregando na página.

## Perguntas frequentes sobre Core Web Vitals e SEO

### Core Web Vitals são fator de ranqueamento do Google?

Sim. Os Core Web Vitals fazem parte dos sinais de "experiência de página" (Page Experience) que o Google usa como parte dos critérios de ranqueamento orgânico, ao lado de fatores como relevância de conteúdo, uso de HTTPS e adequação a dispositivos móveis.

### Quais são as três métricas dos Core Web Vitals?

As três métricas são LCP (Largest Contentful Paint), que mede a velocidade de carregamento do conteúdo principal; INP (Interaction to Next Paint), que mede a velocidade de resposta a cliques e toques; e CLS (Cumulative Layout Shift), que mede a estabilidade visual da página durante o carregamento.

### O que substituiu o FID nos Core Web Vitals?

O INP (Interaction to Next Paint) substituiu o FID (First Input Delay) como métrica oficial de capacidade de resposta do Google. Diferente do FID, o INP avalia a responsividade do site ao longo de toda a visita, não apenas na primeira interação do usuário.

### Melhorar os Core Web Vitals garante a primeira posição no Google?

Não isoladamente. Os Core Web Vitals são um entre vários fatores de ranqueamento, e o conteúdo relevante continua sendo o critério mais importante. Porém, entre páginas com relevância parecida, bons índices de Core Web Vitals podem ser o diferencial que melhora o posicionamento.
